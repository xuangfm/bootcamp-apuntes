## 🔍 Comandos investigados

### git log --oneline
te dice los cambios que hubo y un poco la historia de ese git, subidas, mejoras...
### git remote -v
permite editar las conexiones con los repositorios.

### git branch
Te deja ver las ramas del repositorio.

### git pull
Descarga los cambios que tengas en el servidor y los combina con los que tengas en local.

### .gitignore
a mi éste no me funcionó, buscando por internet encontré que es un archivo de texto que le dice a Git que archivos o carpetas ignorar.

### git add . vs git add archivo

git add: añade todos los archivos del repositorio
git add archivo: solo añade el archivo específico en el nombre.
Por ejemplo, en éste caso se pondría git add dia-01.md, para añadir solo ese archivo.
